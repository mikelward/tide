Name prompt

One prompt for naming a workspace (SPEC.md §6.5): a new window on home asks where it goes, a launch from home asks before it starts, Super+Return goes to a workspace and Super+Shift+Return moves the focused window to one. The first row is the typed name as a new workspace when none has it, then the workspaces that match, scored as the switcher scores. Enter takes the selected row, making the workspace if it's new; Esc closes a new window from home, cancels a launch, and otherwise leaves things as they were. A workspace spans every monitor, so a window moved there stays on its own monitor.

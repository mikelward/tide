Fonts

The same pieces of the shell in four pairings of UI and code fonts, the chosen one first. Chosen: Inter for UI with Ubuntu Mono for code, the default in appearance.json. It is also handed to GTK and Qt, so apps match, and kitty's font stays kitty's own setting. Ubuntu Sans is the 2023 redesign that Ubuntu has shipped as its default since 23.10: variable weights, closer to the classic Ubuntu than Inter is.

Screen and window captures are instant. Region freezes the screen first, so hover menus and tooltips can be caught.

Region (Shift+Print, Super+Print): drag, fine-tune with the handles, then press Enter (or double-click inside) to capture; releasing the drag only sets the region. Space switches to window mode, Esc cancels, and the size is shown in physical pixels. The toolbar can also switch mode or set a delay.

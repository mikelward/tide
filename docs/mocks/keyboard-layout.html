Where the keyboard layout shows

The boot splash can’t put the layout inside the password field: Plymouth’s two-step plugin always draws it under the field and the prompt, as an icon and the layout’s name, with the Caps Lock icon beside it. So the splash and the login screen line up only if the login screen moves its layout to the same place, or one of them leaves it out. Each option shows the disk unlock on the left and the login screen on the right. The lock is the login screen without the user picker, and follows it.

A. Each where it is now

The splash shows the layout under the field, as Plymouth does. The login screen and the lock keep the badge inside the field.

System monitor

Clicking the CPU % in the bar opens one popover. A readout row (CPU, memory, temperature) sits above two tabs. CPU, the default, shows the temperature, the clock (the fastest core's current speed over the fastest core's top), thermal throttling where the kernel counts it, and the five processes using the most CPU, as a share of one CPU, the way top shows it. Memory shows memory and swap, used over total, and the five processes using the most resident memory. The lists refresh every 2 s while the popover is open.
